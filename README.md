# Ejercicios de clase - Java

Repositorio para organizar los ejercicios y prácticas de clase.

## Figuras geométricas

En la carpeta `figuras-geometricas` está el programa con un menú para calcular el área y el perímetro de círculos, cuadrados, trapecios y triángulos.

Con un JDK 11 o superior instalado, ejecuta desde la raíz:

```sh
java figuras-geometricas/MenuFiguras.java
```

Consulta [las instrucciones del ejercicio](figuras-geometricas/README.md) para ver las medidas necesarias y las fórmulas utilizadas.

Los próximos ejercicios pueden añadirse en sus propias carpetas.
