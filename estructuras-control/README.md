# Ejercicios de Estructuras de Control

Solución de seis ejercicios en Java en el archivo `EjerciciosEstructurasControl.java`.

1. Números pares del 1 al 100 con `for`.
2. Números impares del 1 al 100 con `for`.
3. Suma de los primeros 50 números naturales: 1275.
4. Tabla de multiplicar de un número del 1 al 10 con `for`.
5. Factorial de un número con `while`.
6. Mayor de tres números con `if-else`.

## Ejecución

Con un JDK instalado, abre una terminal en esta carpeta y ejecuta:

```sh
javac EjerciciosEstructurasControl.java
java EjerciciosEstructurasControl
```

Los ejercicios se ejecutan en orden. Introduce números enteros cuando se soliciten. El factorial acepta valores de 0 a 20 para que el resultado quepa en un `long`; el factorial de 0 es 1.
